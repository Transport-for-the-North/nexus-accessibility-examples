# Nexus Accessibility Examples

This repository contains the Python notebooks and examples for the Nexus Accessibility
Workshop ran on 09/10/2026. Most of the examples in this repository are written as
[marimo](https://marimo.io/) notebooks but these can be ran as standalone Python scripts
if preferred.

## Molab

The marimo notebooks in this repository can be viewed on [molab](https://molab.marimo.io/github)
by replacing the GitHub domain (`https://github.com/`) with `https://molab.marimo.io/github/`, see
[Marimo - GitHub](https://docs.marimo.io/guides/publishing/github/) for more details.

For example to view the [washington_access.py](./washington_access.py) notebook (*as it
is on the main branch*).

- GitHub URL: <https://github.com/Transport-for-the-North/nexus-accessibility-examples/blob/main/washington_access.py>
- Molab URL: <https://molab.marimo.io/github/Transport-for-the-North/nexus-accessibility-examples/blob/main/washington_access.py>
